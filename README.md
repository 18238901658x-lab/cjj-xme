# US. — A Shared Archive

摄影杂志风的情侣相册网站，原生 HTML / CSS / JavaScript，无须安装依赖。

## 本地启动

安装 Node.js 后，在本目录运行：

```sh
npm start
```

访问 http://127.0.0.1:4173 。终端按 Ctrl+C 停止服务。

## 功能

- 响应式首页、照片墙、示例时光手记。
- 按「我们 / 旅行 / 日常」筛选照片。
- 点击照片放大，左右方向键切换，Esc 关闭。
- 添加本地 JPG、PNG、WebP 图片；浏览器 IndexedDB 保存，刷新仍保留。
- 自定义两人名字和纪念日，计算在一起天数。

照片只存于当前浏览器、当前地址的存储空间中，不会上传服务器，也不会跨设备同步；清除浏览器数据会删除添加的照片，请保留原图。设置保存在 localStorage。

默认示例照片已下载在 dist/assets，来自 Unsplash；示例日期、标题和手记不代表真实经历。修改 dist/app.js 的 samples 可替换默认照片与文案；修改 dist/index.html 可修改首页和手记。使用系统无衬线字体，无外部字体依赖。样式文件为 dist/editorial.css。

服务器仅监听本机 127.0.0.1。本项目未发布到公网。

## Rose Edition 设计

雾粉底色、莓红文字、衬线标题与非对称摄影排版。主题样式为 dist/rose.css，基础布局为 dist/editorial.css。

设计参考：VGROUP 的 Fox & Rose 品牌项目（https://www.vgroup.com/projects/fox-rose/）以及 CSS Design Awards 粉色案例集（https://www.cssdesignawards.com/website-gallery?color=pink）。仅参考配色与设计方向，页面为独立实现，没有复制品牌素材。

## 动态相册

点击首页「进入我们的相册」打开全屏播放器，每 5 秒自动切换照片，支持暂停、左右箭头、缩略图选图和手机左右滑动。在系统开启减少动态效果时，默认不自动播放。关闭相册后停止计时，切到后台时暂停计时。

点击「查看全部照片」进入完整相册，可按分类筛选；点击任意照片进入该分类的大图浏览。「播放这些照片」从当前分类开始播放。新增照片会纳入完整相册与轮播。

## 单张照片与缩放

- 独立缩放工具栏：50%–400%，以适应窗口的尺寸为 100%；「适应窗口」恢复完整照片。
- 支持加减按钮、双击、鼠标滚轮；放大后可拖动查看细节，移动范围限制在图片边界内。
- 触屏实现双指缩放、放大拖动与原尺寸时左右滑动换图。
- 缩放会暂停播放；重新播放和切换照片会恢复适应窗口，避免放大状态带到下一张。
- 循环播放提供 3、5、8 秒选项，最后一张播放后回到第一张。
- 快捷键：左右箭头换图，空格播放或暂停，+ / − 缩放，0 复位，Esc 退出。

已在本地浏览器验证：单张打开、双击、放大拖动、50%/400%边界、复位、自动末张循环、桌面与手机尺寸布局。触屏双指手势已实现，未在实体手机上测试。

## 私人画册版

最新视觉主题为 dist/atelier.css：暖白纸感首页、低饱和灰玫瑰色、错位底板与照片编号，以及深色私人放映室。沿用原有照片、缩放、拖动、轮播和完整相册功能。已检查桌面与手机布局、相册入口及缩放，浏览器无错误日志。

## 互动小宇宙版

最新主题 dist/universe.css，互动脚本 dist/universe.js。墨黑、银白与冰蓝配色；首页照片漂浮、鼠标轻微视差，银白 SVG 小猫眨眼、摇尾、眼神跟随与点击跳跃，金属爱心双节奏跳动并支持点击反馈。右上角可暂停装饰动效；系统开启减少动态效果时自动使用静态模式。

漂浮照片可直接打开查看，原有轮播、缩放和分类功能保留。小猫是网页 SVG 动画，无第三方组件与图片请求依赖。已验证小猫点击、爱心反馈、动效开关、照片入口、缩放与手机布局。

## 明亮 3D 场景版

当前最终视觉为 dist/air.css，使用奶油白、雾蓝与淡杏色；所有相册及弹窗改为浅色。首页使用 CSS perspective / preserve-3d 与不同深度的照片、小球、展示台来建立立体空间，配合照片侧面厚度和投影。鼠标轻微旋转场景；「旋转这个小世界」滑杆可在 −22° 到 22° 之间调整视角，手机同样可用，提供复位按钮。小猫与爱心动画、相册播放及缩放继续保留。这是浏览器原生 CSS 3D 场景，不依赖 WebGL 下载。
